# crystALL Tutorials

Welcome to the crystALL tutorial notebooks. Choose one to get started:

## Available Tutorials

### [01. Quick Start Guide](01.QuickStart.ipynb)
A comprehensive introduction to crystALL's main functionalities. Learn how to identify, categorize, and classify crystal structure prototypes using the BaSO4 (Barium sulfate) example.

**Topics covered:**
- Prototype identification and generation
- Prototype categorization using descriptors
- Clustering and classification
- Data visualization and export
- Candidate structure analysis

### [02. Metal Hydrides Example](02.HydridesExample.ipynb)
A real-world case study demonstrating the discovery of new material structures in metal hydride systems.

**Topics covered:**
- Practical application of crystALL
- Materials discovery workflow
- Advanced structure analysis
